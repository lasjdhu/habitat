# Habitat [![MIT License](https://img.shields.io/badge/license-MIT-22c55e.svg)](LICENSE)

An Android habit tracker that turns everyday consistency into a city-building
experience.

## Motivation

Habit tracking is easier to sustain when progress feels tangible. Habitat
connects daily check-ins to a small 3D world, rewarding routines with visible
growth while keeping all profile and habit data on the device.

## Usage

Install the dependencies, then launch an Android development build:

```bash
pnpm install
pnpm android
```

The app supports habit categories, daily check-ins, profile statistics, local
SQLite persistence, light and dark themes, and an interactive 3D habitat.
